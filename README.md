# Sleeping Server Stopper
[![Modrinth](https://img.shields.io/badge/Modrinth-EmptyServerStopper-green?logo=modrinth&logoColor=white)](https://modrinth.com/project/nuRsj5Nz) Get on Modrinth!

A server-side mod that shuts a dedicated server down once it has been empty for a few minutes. It's a port of the [Sleeping Server Stopper Spigot plugin](https://github.com/vincss/mcEmptyServerStopper), meant to be used with [SleepingServerStarter](https://github.com/vincss/mcsleepingserverstarter) by [vincss](https://github.com/vincss).

Only the server needs the mod. It does nothing in singleplayer or on LAN worlds.

## Config
On first launch the mod writes `config/sleepingserverstoppermod.properties`:

```properties
# How many minutes the server must be empty before it shuts down. (Minimum is 1 minute!)
shutdownTimeInMinutes=2
# Should the shutdown countdown start as soon as the server launches?
shutdownOnLaunch=true
```

> **Upgrading from 3.x:** the old `sleepingserverstoppermod-common.toml` / `.cfg` files are no longer read. Copy your values into the new file.

## Building
Every jar is built from one codebase:

```
core/                  Plain Java 8 logic (countdown, config) shared by every build, with unit tests
src/                   Loader entrypoints for the modern builds, versioned with Stonecutter comments
versions/<mc>-<loader> Generated by Stonecutter, one Gradle project per Minecraft version + loader
legacy/forge-<mc>/     Standalone builds for old Forge versions that need different tooling
```

```sh
./gradlew :core:test                    # unit tests
./gradlew buildAll                      # every modern jar  -> build/libs/<mod version>/
./gradlew :1.21.1-neoforge:build        # one version
./gradlew -p legacy/forge-1.12.2 build  # a legacy version -> legacy/forge-1.12.2/build/libs/
```

Gradle downloads the JDKs it needs automatically, including Java 25 to run Gradle itself.

- Modern versions use [Stonecutter](https://stonecutter.kikugie.dev/) with Fabric Loom, ModDevGradle (NeoForge) and ModDevGradle legacyforge (Forge 1.17 – 1.20.1). Version-specific code uses comments like `//? if <1.19 {`. Switch which version your IDE sees with the Stonecutter tasks in the `stonecutter` Gradle group.
- To add a version, add a `match(...)` line in `settings.gradle.kts` and a matching table in `stonecutter.properties.toml`.
- `legacy/forge-1.16.5` uses Architectury Loom. `legacy/forge-1.12.2` and `legacy/forge-1.7.10` use [RetroFuturaGradle](https://github.com/GTNewHorizons/RetroFuturaGradle).
- The mod version is set once, in `stonecutter.properties.toml`.

## 📄 Versions
- **v4.0.0**
  - Supports Fabric, NeoForge and Forge from one codebase, for 1.7.10 up to 26.3.
  - New loader-independent config file, `config/sleepingserverstoppermod.properties`.
  - Fixes:
    - The shutdown now runs on the server thread.
    - Joining and leaving repeatedly no longer stacks up shutdown timers.
    - The last player leaving now starts the countdown on every version. On 1.7.10 it never did.
    - The countdown keeps working while a 1.21.2+ server is paused for being empty.
    - Clients without the mod can join 1.7.10 and 1.12.2 servers.
    - The mod does nothing in singleplayer or on LAN.
- **v3.0.0**
  - Config file's `shutdownOnLaunch` value now works.
- **v2.0.0**
  - Config file with `SHUTDOWN_TIME_IN_MINUTES` (minimum 1) and `SHUTDOWN_SERVER_ON_LAUNCH`, defaulting to (2, true).
  - Fixed 2 minor bugs.
- **v1.0.0**
  - Hard-coded values: a 2 minute timer, and the server shuts down on startup.

The pre-4.0 project layout (one Forge project per version) is kept under the `pre-restructure` git tag.
